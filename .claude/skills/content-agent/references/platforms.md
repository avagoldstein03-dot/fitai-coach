# Platform specs

Active AI posts to **TikTok, Instagram (Reels + carousels), and YouTube Shorts**. Every caption or hashtag output is produced per platform, never one version pasted to all three.

Platform limits change often. The numbers below were current when written; if one looks off, check the platform's own help page before relying on it.

| | TikTok | Instagram | YouTube Shorts |
|---|---|---|---|
| Discovery driver | Keywords in caption + on-screen text + spoken words | Keywords in caption + hashtags | Title keywords (search-driven) |
| Caption style | 1–2 short lines, keyword-rich, conversational | Hook line visible before "more" (~125 chars), then value, then CTA | **Title** ≤100 chars (aim ≤60 so it isn't truncated) + short description |
| Hashtags | 3–5, niche over broad | **Max 5** (Instagram's current cap) | 1–3 in the title or description; the first 3 show above the title |
| CTA wording | "link in bio" | "link in bio" / "comment WORD and I'll DM you" | "link in description" / pinned comment |

## Comment-keyword CTA

"Comment PROTEIN and I'll send you ___." The keyword triggers an automated DM (e.g. via ManyChat, Phase 4). Rules:
- One short, all-caps, on-topic keyword per post.
- Only offer something that actually exists (the app link, a real free feature, a real guide).
- Until the DM automation is live, don't use this CTA: a promised DM that never arrives costs trust.
