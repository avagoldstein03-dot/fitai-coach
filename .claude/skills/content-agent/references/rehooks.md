# Re-hook library

A re-hook is a moment mid-video that resets attention right where viewers would otherwise drop off. Source: peter.visuals' "30 ways to re-hook a viewer," adapted here to Active AI and its brand rules.

**Placement rule of thumb (short-form, ~125 wpm):**
- A *pattern interrupt* (visual OR verbal) every 3–5 seconds (~6–10 spoken words).
- A *spoken* re-hook every ~8–12 seconds. Denser than that and the script reads like a string of teasers with no payoff.
- Every re-hook must be paid off later in the same video. A tease with no payoff is worse than no tease.

## Spoken re-hooks (1–20)

| # | Type | Template | Active AI example | Brand-rule note |
|---|------|----------|------------------|-----------------|
| 1 | Ask a question | "Why does this happen?" | "so why was my score low when I *felt* fine?" | |
| 2 | Add a problem | "But there's one problem…" | "but there's one problem — I don't own a smartwatch" | |
| 3 | Tease what's coming | "Wait until you see the final result." | "wait till you see what it said about my protein" | Payoff must be a real screen |
| 4 | Show proof | "Here's the proof." | "here's the actual screen" → cut to real screenshot | Real screenshot only |
| 5 | Add a twist | "But then something weird happened." | "then it swapped my squats for something else" (injury-aware) | |
| 6 | Show a comment | Bring a comment on screen | Reply-to-comment format | **Real comments only, never generated** |
| 7 | Make a comparison | "A vs. B." | "$9.99 vs. what I was paying for three apps" | Only real, verifiable prices |
| 8 | Reveal a mistake | "Here's where I went wrong." | "I was eyeballing my macros for a year" | |
| 9 | Before & after | "Before → After." | "week one vs. week eight of my streak" | No body-transformation claims |
| 10 | Warn them | "Don't do this yet." | "don't buy a fitness tracker yet" | |
| 11 | Reveal a number | "Only 3% did this." | "zero ads. not fewer — zero." | **Sourced stat or real product fact only** |
| 12 | Challenge them | "Can you spot the mistake?" | "guess which of these has more protein" | |
| 13 | Hold back the answer | "Before I tell you why…" | "before I tell you what the number means…" | |
| 14 | Show an example | "Here's what I mean." | cut to real screen | Real screenshot only |
| 15 | Correct yourself | "Actually… that's wrong." | "actually no, it's not a sleep tracker" | |
| 16 | Raise the stakes | "And it gets worse." | "and I was doing that *five days a week*" | |
| 17 | Reveal something hidden | "Here's what you don't see." | "what you don't see is it checks ingredients too" | |
| 18 | Add an exception | "Unless you're doing this…" | "unless you're on a GLP-1 — then protein matters more" | Generic drug class, never brand names |
| 19 | Make a prediction | "Here's what happens next." | "watch, tomorrow's score goes up" | Only if the video shows it |
| 20 | Add another benefit | "But that's not even the best part." | "and that part's free on every plan" | Only for genuinely free features (readiness, life-stage) |

## Visual / edit re-hooks (21–30)

For the UGC pipeline these become generation or edit instructions. Screen-based ones must use a real image from `backend/scripts/marketing-automation/screenshot-assets/` (`dashboard`, `coach`, `workouts`, `foodscanner`, `bodyscan`, `weekly`, `achievements`, `friends`, `onboarding`, `pricing`) composited in the edit. Never let a generator render app UI.

| # | Move | How to specify it |
|---|------|-------------------|
| 21 | Switch the shot | Cut to a second angle, e.g. from eye-level 18" to a 45° side angle |
| 22 | Cut to B-roll | 1–2 s of the thing mentioned (a meal, a gym bag, a pill organizer, never a branded drug) |
| 23 | Use a prop | Bring an object into frame (water bottle, food package for the scanner) |
| 24 | Zoom in | Punch in ~20% on the key line |
| 25 | Change location | Continue the sentence in a new room or outside |
| 26 | Switch the format | Talking head → full-screen real screenshot |
| 27 | Bring in another person | A second voice or face (friend, partner), good for the Referral and Community features |
| 28 | Pause before the payoff | A deliberate 0.5–1.0 s pause (state the max length) |
| 29 | Call back to the hook | "remember when I said…" in the last 20% |
| 30 | Open another question | Close on a new question that sets up a part 2 |
